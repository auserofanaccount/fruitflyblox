
# FruitFlyBlox

This was made to prove some idiots that it actually DOES control ROBLOX itself.

# How to setup?
- Clone the repository, cd into it and run the following commands.

```pip install -r requirements.txt```

- Get the required CSV files.

Linux

```wget https://storage.googleapis.com/flywire-data/codex/data/fafb/783/connections_princeton.csv.gz && wget https://storage.googleapis.com/flywire-data/codex/data/fafb/783/classification.csv.gz```

Powershell

```
Invoke-WebRequest -Uri "https://storage.googleapis.com/flywire-data/codex/data/fafb/783/connections_princeton.csv.gz" -OutFile "connections_princeton.csv.gz"
Invoke-WebRequest -Uri "https://storage.googleapis.com/flywire-data/codex/data/fafb/783/classification.csv.gz" -OutFile "classification.csv.gz"
```

- Unzip the CSV files.

Linux:

```for f in *.csv.gz; do gunzip -k "$f"; done```

Powershell:

```
Get-ChildItem -Filter *.csv.gz | ForEach-Object {
    $inFile = $_.FullName
    $outFile = $_.FullName -replace '\.gz$', ''
    $streamIn = New-Object System.IO.Compression.GZipStream([System.IO.File]::OpenRead($inFile), [System.IO.Compression.CompressionMode]::Decompress)
    $streamOut = [System.IO.File]::Create($outFile)
    $streamIn.CopyTo($streamOut)
    $streamOut.Close()
    $streamIn.Close()
}
```

- Run the python script.

```python main.py```

- Focus to ROBLOX and you're good to go.
